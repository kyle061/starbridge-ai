# OpenAI 新模型发现与账号准入

上游 `/models` 或 Codex 模型清单返回的新 GPT 版本不应再被本地静态型号表丢弃。静态清单仅用于预设和故障兜底；真实清单保留上游能力字段。账号含通配规则时，模型清单走实时发现，即使分组未开启白名单。

账号或分组已明确启用至少一个 GPT-6 或更新的具体文本型号后，实时发现的 GPT-6 及后续编号文本版本会自动加入候选、模型列表和分组白名单，无需每次升级时改白名单。账号映射若把 GPT 型号改写为别的上游型号，则不触发自动放行；图片、其他厂商和内部审批模型不受此规则影响。上游账号仍须实际提供该模型，且自动放行的新型号必须能从已配置的动态价目或明确价目中确认价格后才会转发和计费。

2026-10-18 核实的 `gpt-6.1-sol` 使用独立型号和价格，绝不转发成 `gpt-6-sol`。官方标准价（USD / 百万 token）为输入 2、输出 10、缓存读取 0.10、缓存写入 2.50；Fast 为标准价 2 倍，长上下文阈值为 272000 输入 token。官方能力为 1050000 上下文，推理档位 low / medium / high / xhigh / max，不包含 none / minimal。实时清单优先保留账号实际返回的能力。

来源：https://developers.openai.com/api/docs/models/gpt-6.1-sol

若返回 `Model ... is not supported by any configured account in this group`，检查当前分组账号的 `model_mapping`。这是本地账号准入诊断，不能据此断言上游尚未发布该模型。若请求被价格守卫拒绝，应配置已核实的新模型价格或刷新动态价格源，不应猜用旧型号价格。
