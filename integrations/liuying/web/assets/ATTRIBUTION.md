# Media and Icons

- `demo.mp4`, `demo.jpg`, `demo-detail.jpg` and `demo-images.zip`: MDN interactive examples CC0 flower video, https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4 . The still is extracted from the same video; the detail image is a crop and the ZIP bundles these two demonstration images. This is explicitly labeled as a demo and is not a parsing result from a supported social platform.
- SVG and PNG tool icons: Lucide, ISC license. See `LUCIDE-LICENSE`. Generated with `scripts/build-assets.mjs` using the library's icon nodes.
